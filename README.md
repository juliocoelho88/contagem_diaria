# Contagem Diária 🚔

Este projeto é uma aplicação de controle de contagem diária para facilitar o registro de eventos operacionais. A aplicação é desenvolvida em Python utilizando Tkinter para a interface gráfica e SQLite para o banco de dados.

## 📌 Funcionalidades
- **Cadastro de Registros:** Armazena dados operacionais.
- **Consulta de Registros:** Visualiza dados cadastrados.
- **Edição de Registros:** Atualiza informações existentes.
- **Exclusão de Registros:** Remove dados obsoletos.
- **Exportação para Excel:** Permite análise e relatórios.

## ⚙️ Instalação e Execução
1. **Clone o repositório:**
   ```bash
   git clone https://github.com/juliocoelho88/contagem_diaria.git
   cd contagem_diaria
   ```

2. **Crie um ambiente virtual e instale as dependências:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   venv\Scripts\activate    # Windows
   pip install -r requirements.txt
   ```

3. **Execute a aplicação:**
   ```bash
   python main.py
   ```

## 🛠 Tecnologias Utilizadas
