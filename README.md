# Contagem Diária

Este projeto é uma aplicação para gerenciar registros diários. Inclui funcionalidades de CRUD (Criar, Consultar, Atualizar, Deletar) e exportação de dados.

## Funcionalidades
- Adicionar novos registros
- Consultar registros existentes
- Editar registros
- Deletar registros
- Exportar registros para Excel

## Requisitos
- Python 3.9 ou superior
- Bibliotecas listadas em `requirements.txt`
